# Skills

A rough map of the tools I reach for most often. Nothing here is a ranking —
just the things that tend to show up across most of the work.

## Frontend

- **React** — hooks, context, and the occasional suspense boundary.
- **TypeScript** — strict mode, discriminated unions, and a healthy distrust of `any`.
- **Tailwind CSS** — utility-first styling with a small set of design tokens.
- **Vite** — dev server and build tooling for most projects.

## Backend

- **Node.js** — APIs, scripts, and small services.
- **PostgreSQL** — schema design and the queries that go with it.
- **REST & JSON** — the boring interface that keeps working.

## Tooling

- **Git** — branching, rebasing, and reading history before blaming it.
- **Linux** — a terminal-first workflow on a daily driver.
- **Docker** — reproducible environments when a machine is not enough.

## Practices

- Write it down before building it.
- Prefer the simplest thing that could work.
- Leave the code better than you found it.
